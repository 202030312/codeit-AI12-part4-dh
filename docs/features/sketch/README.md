# 스케치를 광고로 완성하기

상품과 소품의 대략적인 배치를 그린 스케치와 요청사항을 바탕으로 광고 이미지를
생성하는 기능입니다.

## 작동 방식

1. 스케치에서 상품 위치, 크기와 전체 구도를 참고합니다.
2. 한국어 요청사항을 FLUX 실행용 프롬프트로 변환합니다.
3. `black-forest-labs/FLUX.2-klein-4B`가 스케치와 요청을 반영한 이미지를 생성합니다.
4. 스케치와 결과 이미지를 나란히 표시하고 PNG 다운로드를 제공합니다.

## 사용 방법

1. `스케치를 광고로 완성하기` 메뉴에서 스케치 이미지를 업로드합니다.
2. 상품 종류, 색감, 배경 분위기, 조명과 문구용 여백을 입력합니다.
3. 결과를 확인하고 PNG로 내려받습니다.

스케치의 화살표, 네모 상자와 안내 문자는 실제 오브제가 아니라 배치 안내로 처리합니다.
다만 모델이 안내선을 재현할 수 있으므로 테스트에서는 불필요한 표시를 지운 깨끗한
스케치를 권장합니다. 직접 실행할 때는 L4급 GPU가 있는 Colab 환경을 권장합니다.
