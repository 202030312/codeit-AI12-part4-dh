# 광고 문구 추천

상품 이미지와 사용자가 입력한 상품 정보를 바탕으로 SNS 광고용 제목과 보조 문구
후보를 제안하는 기능입니다.

## 작동 방식

1. Gemini가 상품 이미지에서 직접 확인할 수 있는 상품 유형, 색상, 구성과 장식 정보를 추출합니다.
2. 추출된 시각 정보에 메뉴명, 상품 특징, 가격, 행사 정보와 추가 요청사항을 결합합니다.
3. GPT가 제목과 선택적 보조 문구 후보 2개를 생성합니다.
4. 입력에 없는 사실, 위험 표현, 금지어, 길이와 후보 유사도를 검사합니다.
5. 검증에 실패한 후보만 다시 생성하고 유효한 후보는 그대로 유지합니다.

## 사용 방법

1. `광고 문구 추천` 메뉴에서 상품 이미지를 업로드합니다.
2. 메뉴명과 상품 특징을 입력하고 필요한 경우 가격, 행사 정보와 문구 요청사항을 추가합니다.
3. 생성 버튼을 누르고 후보 2개 중 사용할 문구를 선택합니다.
4. 문구 TXT, 생성 정보 JSON 또는 배너 묶음 ZIP을 내려받습니다.

Gemini와 OpenAI API를 사용하므로 `.env`에 `GEMINI_API_KEY`와
`OPENAI_API_KEY`가 필요합니다. 이미지에서 확인되지 않거나 사용자가 제공하지 않은
재료·효능·수치는 광고 문구의 근거로 사용하지 않습니다.
