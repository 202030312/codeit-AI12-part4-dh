# 상품 사진 꾸미기

입력한 상품의 모양과 색상은 유지하면서 배경, 분위기와 광고 구성을 새롭게 만드는
기능입니다.

## 작동 방식

1. 업로드한 상품 이미지에서 배경을 제거해 투명 PNG 상품 컷을 만듭니다.
2. 선택한 템플릿 또는 요청한 분위기에 맞춰 배경과 상품 위치를 구성합니다.
3. 원본 상품의 RGB 정보를 유지한 상태로 1080×1080 광고 이미지에 합성합니다.
4. 선택한 광고 문구가 있으면 안전 영역에 배치해 최종 배너를 생성합니다.

## 사용 방법

1. `상품 사진 꾸미기` 메뉴에서 상품 사진을 업로드합니다.
2. 원하는 템플릿과 배경 분위기를 선택합니다.
3. 결과를 확인하고 상품 이미지 또는 문구가 포함된 광고 배너를 내려받습니다.

이 기능은 상품을 다른 메뉴로 교체하지 않습니다. 상품 종류나 외형 자체를 바꾸려면
`사진 새롭게 바꾸기` 기능을 사용합니다.
