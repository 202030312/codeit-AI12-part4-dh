# 사진 새롭게 바꾸기

업로드한 사진을 레퍼런스로 사용해 상품, 배경, 분위기와 카메라 구도를 사용자의
요청대로 변경하는 기능입니다.

## 작동 방식

1. 레퍼런스 이미지와 한국어 요청사항을 이미지 편집용 내부 프롬프트와 결합합니다.
2. 변경할 대상과 유지할 대상을 구분해 `gpt-image-2.5-sunburst`에 전달합니다.
3. 원본과 생성 결과를 나란히 표시하고 PNG 다운로드를 제공합니다.

## 사용 방법

1. `사진 새롭게 바꾸기` 메뉴에서 참고할 사진을 업로드합니다.
2. 바꿀 상품이나 배경, 계절감, 분위기 또는 카메라 각도를 짧게 입력합니다.
3. 생성 결과를 원본과 비교한 뒤 PNG로 내려받습니다.

예: `말차라떼를 딸기라떼로 바꾸고 컵 아래에 딸기 과육층이 보이게 해주세요.`

이 기능은 입력 상품을 반드시 보존하는 기능이 아닙니다. 상품을 그대로 유지해야 하는
경우에는 `상품 사진 꾸미기`를 사용합니다.
